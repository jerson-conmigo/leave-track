# LeaveTrack UI — Design System

> **Generated by Claude during Day 0 `/scaffold` — NOT derived from Figma.** No design export
> existed for this project. When a real design source arrives, reconcile it against this spec and
> `app/globals.css`, then update both together.

Implementation: `app/globals.css` (tokens) · `components/ui/` (shadcn primitives) ·
`components/<domain>/` (feature components).

## Principles

1. **Calm and trustworthy.** It's an HR tool about people's time off — clear, quiet, no decoration.
2. **Phone-first.** ~30% of staff are mobile-only (BR-05). Every screen works at 320px.
3. **Status at a glance, never by color alone.** Every status and leave type pairs an icon with text.
4. **Numbers are the content.** Balances use large, tabular figures.

## Color tokens

All colors are `hsl()` CSS custom properties on `:root`, exposed to Tailwind via `@theme inline`
(so `bg-primary`, `text-muted-foreground`, `bg-status-pending`… all work, including opacity
modifiers such as `bg-primary/10`). Never use raw hex/rgb/oklch in components.

## Typography

- **Geist Sans** (UI) and **Geist Mono** (codes, IDs) from the `geist` package — self-hosted, so
  builds need no network. Exposed as `font-sans` / `font-mono`.
- Scale (Tailwind): `text-xs` meta · `text-sm` UI default · `text-base` inputs on mobile (prevents
  iOS zoom) · `text-lg` section headings · `text-2xl` page titles · `text-3xl` balance figures.
- Weights: 400 body, 500 labels/nav, 600 headings and figures.
- Balances and counts use `tabular-nums`.

## Spacing, radius, elevation

- 4px Tailwind scale. Page gutter `px-4` → `md:px-6` → `lg:px-8`; content max width `max-w-6xl`
  (forms `max-w-2xl`). Vertical rhythm: `gap-4` within groups, `mb-8` between sections.
- Radius: `--radius: 0.625rem` → `rounded-sm` (6px), `rounded-md` (8px), `rounded-lg` (10px),
  `rounded-xl` (14px).
- Elevation: `shadow-xs` on cards/lists; `shadow-lg` only on overlays (dialog, sheet, menu).

## Layout & breakpoints

Tailwind defaults: `sm` 640 · `md` 768 · `lg` 1024 · `xl` 1280.

| Width    | Shell                                                | Data views               |
| -------- | ---------------------------------------------------- | ------------------------ |
| < 1024px | Sticky 56px top bar · menu button opens left `Sheet` | Stacked cards below `md` |
| ≥ 1024px | Fixed 16rem sidebar + 64px top bar                   | Tables from `md` up      |

- No horizontal scroll at 320/375px (US-06). Long text truncates in tables, wraps in cards.
- Touch targets ≥ 44px below `md`: buttons `h-11`, inputs/selects `h-11`, nav links `h-11`;
  they relax to 36px (`md:h-9`) on desktop.
- Dates use native `<input type="date">` for the best mobile picker.

## Iconography

- `lucide-react` only. Sizes: 16px inline (`size-4`, shadcn default), 20px nav (`size-5`),
  24–28px in empty/status screens. Stroke 2.
- Decorative icons: `aria-hidden`. Icon-only buttons: `aria-label`.
- Center icons with flex or `mx-auto` — never parent `text-align: center`.
