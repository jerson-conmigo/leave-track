# Token Efficiency

- Inspect only files relevant to the current task.
- Avoid unnecessary repository-wide searches.
- Never reread files without a reason.
- Prefer targeted changes over large refactoring.
- Avoid unnecessary explanations and progress updates.
- Use targeted tests whenever possible.
- Do not spawn subagents unless they provide clear value.
- Use Opus Advisor only for complex architectural decisions,
  difficult debugging, or critical code reviews.
- Summarize completed work concisely.
- Never compromise correctness for token savings.
